# CI routing

> Generated by AtlasMind from `ci-routing.json`. Edit the JSON, or the Pipeline page.

Where each kind of check runs, and what happens when the hosted allowance is gone.

## One rule that no file can change

A workload whose input has **not been reviewed** may only run on a route that is safe for untrusted
code. AtlasMind applies that before it looks at the budget and applies it to every fallback, so an
exhausted allowance produces a refusal rather than moving unreviewed code onto somebody's computer.
A rule that asks for otherwise is reported as an error and is not acted on.

## Kinds of check

| Workload | Needs evidence from | Approximation | Input |
|---|---|---|---|
| **Fast feedback** — Type checks, lint and unit tests — the ones you want before pushing. | this-machine | acceptable | trusted |
| **Full test suite** — Everything, including the slow tests, on a clean checkout. | linux-container | acceptable | trusted |
| **Platform matrix** — Evidence on operating systems other than the one you are sitting at. | declared-matrix | acceptable | trusted |
| **Packaging and release artifacts** — Building the artifact that would actually ship, from a clean tree. | linux-container | not acceptable | trusted |
| **Security and dependency scanning** — Secret scanning over full history, SAST and dependency audits. | linux-container | not acceptable | trusted |
| **Contributions not yet reviewed** — Pull requests from forks, and any code nobody trusted has read. | declared-matrix | acceptable | untrusted |

## Rules

| Rule | Workload | Prefers | Falls back to | If the allowance is gone |
|---|---|---|---|---|
| `fast-feedback-here` | Fast feedback | Run here | GitHub-hosted runners | use the fallback |
| `full-suite-hosted` | Full test suite | GitHub-hosted runners | Lend this computer to GitHub | use the fallback |
| `packaging-hosted` | Packaging and release artifacts | GitHub-hosted runners | Lend this computer to GitHub | use the fallback |
| `security-scan-hosted` | Security and dependency scanning | GitHub-hosted runners | Lend this computer to GitHub | use the fallback |
| `platform-matrix-hosted` | Platform matrix | GitHub-hosted runners | — | stop |
| `untrusted-hosted-only` | Contributions not yet reviewed | GitHub-hosted runners | — | stop |

## Notes

- `fast-feedback-here` — Immediate feedback on the working copy. Spends no hosted allowance.
- `full-suite-hosted` — A clean checkout settles this. The borrowed machine can stand in when the allowance is gone.
- `security-scan-hosted` — Secret scanning needs full history, which both routes have.
- `platform-matrix-hosted` — No other route can produce evidence for an operating system you are not sitting at.
- `untrusted-hosted-only` — Never falls back. Running unreviewed code on a personal machine is not a budget decision.

## When the allowance cannot be read

This project uses the preferred route when the allowance cannot be read, and says so. An unreadable meter is not an empty one.
